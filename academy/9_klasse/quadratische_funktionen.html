Merkhilfe

📐 Formen

  • Normalform: ax² + bx + c
  • Scheitelpkt: a(x−d)² + e
  • d = −b/(2a) · e = f(d)

🌙 Mitternachtsformel

x₁,₂ = (−b ± √D) / 2a

D = b² − 4ac

  • D > 0 → 2 Nullstellen
  • D = 0 → 1 Nullstelle
  • D < 0 → keine Nullstelle

📈 Öffnung

  • a > 0 → nach oben geöffnet ∪
  • a < 0 → nach unten geöffnet ∩
  • |a| groß → schmaler
  • |a| klein → breiter
