Merkhilfe

📐 Geradengleichung

f(x) = m·x + b

  • m = Steigung
  • b = y-Achsenabschnitt

📈 Steigung

m = Δy / Δx

  • m > 0 → steigend
  • m < 0 → fallend
  • m = 0 → waagerecht

✂️ Nullstelle

f(x₀) = 0

m·x₀ + b = 0

x₀ = −b / m
