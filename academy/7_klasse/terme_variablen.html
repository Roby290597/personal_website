Merkhilfe – Terme & Variablen

📝 Begriffe

  • Variable: Platzhalter (x, y, …)
  • Koeffizient: Zahl vor der Variable
  • Termglied: Summand im Term
  • Konstante: Zahl ohne Variable

✂️ Vereinfachen

  • Gleiche Variablen zusammenfassen
  • 3x + 5x = 8x
  • Konstanten zusammenfassen
  • 3x + 2 + x − 1 = 4x + 1

⚖️ Gleichungen

  • Gleiche Operation auf beide Seiten
  • 2x + 3 = 11
  • 2x = 8
  • x = 4
