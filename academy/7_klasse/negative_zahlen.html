Merkhilfe – Negative Zahlen

➕ Addition

  • pos + pos → größer
  • neg + neg → kleiner
  • pos + neg → Differenz der Beträge
  • (−5) + 3 = −2

➖ Subtraktion

  • a − b = a + (−b)
  • Minus + Minus = Plus
  • 5 − (−3) = 5 + 3 = 8

✖️ Multiplikation

  • (+)(+) = +
  • (−)(−) = +
  • (+)(−) = −
  • (−3) × (−4) = +12
